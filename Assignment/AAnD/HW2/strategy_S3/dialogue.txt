# 平面最近点对问题的分治算法

## 第一部分：算法思路

**问题定义**：给定平面上 n 个点 P = {p₁, p₂, …, pₙ}，求欧几里得距离最小的一对点 (pᵢ, pⱼ)（i ≠ j），输出该最小距离及对应的两个点。

**暴力解法的问题**：枚举所有 C(n,2) 点对，时间复杂度 O(n²)，当 n 很大时不可接受。

**分治算法的核心思想**：把一维的二分搜索推广到二维，通过“预排序 + 带状区域剪枝”把合并步骤压到线性时间。

### 1. 预处理（关键技巧）
在递归开始之前，把点集按两种顺序各排一次：
- `Px`：按 x 坐标升序排列的点数组
- `Py`：按 y 坐标升序排列的点数组

这一步代价是 O(n log n)。之所以要同时维护两份有序数组，是为了让递归的每一层都能以 O(n) 的代价把 Py 切成左右两半，从而避免每层重新排序。

### 2. 分解（Divide）
取当前子集中间位置的横坐标 `mid_x = Px[mid].x`，用一条垂直线 L: x = mid_x 把点集划分为左右两半：
- 左半 Q = 前 ⌈n/2⌉ 个点（按 x 序）
- 右半 R = 其余 ⌊n/2⌋ 个点

由于 Py 已按 y 有序，只需用一个成员判定表（记录哪些点属于左半）扫描一遍 Py，即可在 O(n) 内拆出 `Qy` 和 `Ry`。

### 3. 解决（Conquer）
递归地在 Q 和 R 内部求解最近点对，得到：
- δ₁ = 左半内部的最近距离
- δ₂ = 右半内部的最近距离

令 **δ = min(δ₁, δ₂)**。这就意味着：全局最近点对要么完全在左半、要么完全在右半（已被 δ 覆盖），要么**跨越分割线**。

### 4. 合并（Merge）—— 算法精髓
只需考虑“跨线点对”，且只需考虑**距离分割线水平距离不超过 δ 的竖直带状区域**：

> 若某点在带外（|x − mid_x| > δ），则它到分割线的距离已超过 δ，它与任何另一侧点的距离必然大于 δ，不可能构成更优解。

把带状区域内的点按 y 升序取出，构成序列 `S`。对 `S` 中每个点，只需检查它**之后至多 7 个**点（证明见第五部分），更新 δ。

合并阶段总代价：构造 S 是 O(n)，检查是 O(n × 7) = O(n)，故为 **O(n)**。

### 5. 递归出口
当子集点数 ≤ 3 时直接暴力枚举（最多 3 对），返回其最小距离与对应点对。

## 第二部分：伪代码

```
// ========== 主过程 ==========
CLOSEST-PAIR(P):
    n ← |P|
    if n < 2: return (∞, none, none)
    Px ← P sorted by x-coordinate      // 并列按 y 稳定排序
    Py ← P sorted by y-coordinate
    (d, a, b) ← SOLVE(Px, Py)
    return (d, a, b)


// ========== 分治主体 ==========
SOLVE(Px, Py):                          // |Px| == |Py| == m
    m ← |Px|
    // ---- 递归出口：小规模直接暴力 ----
    if m <= 3:
        best ← ∞ ; pair ← (nil, nil)
        for i ← 0 to m-1:
            for j ← i+1 to m-1:
                dist ← DISTANCE(Px[i], Px[j])
                if dist < best:
                    best ← dist ; pair ← (Px[i], Px[j])
        return (best, pair)

    // ---- Divide ----
    mid ← ⌊m / 2⌋
    Qx ← Px[0 .. mid]                   // 左半，按 x 有序
    Rx ← Px[mid+1 .. m-1]               // 右半，按 x 有序
    midX ← Px[mid].x                    // 分割线位置

    // ---- 线性拆分 Py（保持 y 有序）----
    LEFTSET ← { q : q ∈ Qx }             // 哈希集合，O(m)
    Qy ← [ ] ; Ry ← [ ]
    for each point p in Py:              // O(m)
        if p ∈ LEFTSET: append p to Qy
        else:           append p to Ry

    // ---- Conquer ----
    (δ1, pa1) ← SOLVE(Qx, Qy)
    (δ2, pa2) ← SOLVE(Rx, Ry)
    if δ1 <= δ2: (δ, bestPair) ← (δ1, pa1)
    else:        (δ, bestPair) ← (δ2, pa2)

    // ---- Merge：带状区域检查 ----
    STRIP ← [ ]
    for each point p in Py:              // 天然按 y 有序
        if |p.x - midX| < δ: append p to STRIP

    k ← |STRIP|
    for i ← 0 to k-1:
        j ← i + 1
        while j < k and (STRIP[j].y - STRIP[i].y) < δ:   // 循环体最多执行 7 次
            d ← DISTANCE(STRIP[i], STRIP[j])
            if d < δ:
                δ ← d ; bestPair ← (STRIP[i], STRIP[j])
            j ← j + 1

    return (δ, bestPair)


DISTANCE(a, b) = sqrt((a.x-b.x)² + (a.y-b.y)²)
```

## 第三部分：完整代码

```python
"""
平面最近点对问题 —— 分治算法 O(n log n)

用法：
    python closest_pair.py                # 运行内置测试与随机对拍
    python closest_pair.py --n 200000     # 生成随机点并测性能
"""

from __future__ import annotations

import math
import random
import sys
from typing import List, Sequence, Tuple

# 距离用 float；inf 表示“不存在点对”
Point = Tuple[float, float]
Result = Tuple[float, Point, Point]


# ----------------------------------------------------------------------
# 工具函数
# ----------------------------------------------------------------------
def _dist_sq(a: Point, b: Point) -> float:
    """两点欧氏距离的平方（避免开方，减少误差与开销）。"""
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy


def _brute_force(pts: Sequence[Point]) -> Result:
    """暴力枚举，仅用于递归出口和小规模正确性对拍。O(k^2)"""
    best = math.inf
    ba = bb = None
    k = len(pts)
    for i in range(k):
        for j in range(i + 1, k):
            d2 = _dist_sq(pts[i], pts[j])
            if d2 < best:
                best, ba, bb = d2, pts[i], pts[j]
    return (best, ba, bb)


# ----------------------------------------------------------------------
# 分治核心：全程使用「距离平方」比较，最后再开方
# ----------------------------------------------------------------------
def _solve(px: List[Point], py: List[Point]) -> Result:
    """
    px: 当前子集按 x 升序（并列按 y 升序）
    py: 当前子集按 y 升序（并列按 x 升序）
    返回 (最小距离平方, 点A, 点B)
    """
    m = len(px)

    # ---------- 递归出口：<=3 个点直接暴力 ----------
    if m <= 3:
        return _brute_force(px)

    # ---------- Divide ----------
    mid = m >> 1
    qx = px[:mid]                 # 左半
    rx = px[mid:]                 # 右半
    mid_x = px[mid][0]            # 分割线 x = mid_x

    # ---------- 线性拆分 py，两侧各自保持 y 有序 ----------
    left_ids = {id(p) for p in qx}          # 用对象 id 做 O(1) 成员判定
    qy: List[Point] = []
    ry: List[Point] = []
    for p in py:
        (qy if id(p) in left_ids else ry).append(p)

    # ---------- Conquer ----------
    d1, a1, b1 = _solve(qx, qy)
    d2, a2, b2 = _solve(rx, ry)

    if d1 <= d2:
        delta_sq, best = d1, (a1, b1)
    else:
        delta_sq, best = d2, (a2, b2)

    # ---------- Merge：带状区域内每个点最多向后看 7 个点 ----------
    delta = math.sqrt(delta_sq)
    strip: List[Point] = [p for p in py if abs(p[0] - mid_x) < delta]

    n_strip = len(strip)
    for i in range(n_strip):
        pi = strip[i]
        # 纵向差已达 delta 即停止；由几何论证，内层循环次数 <= 7
        for j in range(i + 1, n_strip):
            pj = strip[j]
            if pj[1] - pi[1] >= delta:
                break
            d2_ = _dist_sq(pi, pj)
            if d2_ < delta_sq:
                delta_sq, best, delta = d2_, (pi, pj), math.sqrt(d2_)

    return (delta_sq, best[0], best[1])


# ----------------------------------------------------------------------
# 对外接口
# ----------------------------------------------------------------------
def closest_pair(points: Sequence[Point]) -> Tuple[float, Point, Point]:
    """
    求平面最近点对。

    参数: points —— 可迭代的 (x, y) 序列
    返回: (最近距离, 点A, 点B)；点数 < 2 时返回 (inf, None, None)

    时间复杂度 O(n log n)，空间复杂度 O(n)。
    """
    pts = list(points)
    n = len(pts)
    if n < 2:
        return (math.inf, None, None)

    # 去重优化：若存在完全重合的两点，最近距离必为 0，可直接返回
    seen = set()
    for p in pts:
        key = (p[0], p[1])
        if key in seen:
            return (0.0, key, key)
        seen.add(key)

    px = sorted(pts, key=lambda p: (p[0], p[1]))   # 预排序：O(n log n)
    py = sorted(pts, key=lambda p: (p[1], p[0]))   # 预排序：O(n log n)

    d_sq, a, b = _solve(px, py)
    return (math.sqrt(d_sq), a, b)


def brute_closest_pair(points: Sequence[Point]) -> Tuple[float, Point, Point]:
    """O(n^2) 参考实现，用于验证分治结果。"""
    d_sq, a, b = _brute_force(list(points))
    return (math.sqrt(d_sq) if math.isfinite(d_sq) else math.inf, a, b)


# ----------------------------------------------------------------------
# 演示 / 测试
# ----------------------------------------------------------------------
def _demo():
    print("=" * 62)
    print("示例 1：手工给定点集")
    print("=" * 62)
    sample = [(2, 3), (12, 30), (40, 50), (5, 1), (12, 10),
              (3, 4), (30, 3), (15, 19), (20, 30), (1, 2)]
    for p in sample:
        print(f"  {p}")
    d, a, b = closest_pair(sample)
    print(f"\n  >>> 最近距离 = {d:.6f}")
    print(f"  >>> 最近点对 = {a}  和  {b}")

    print("\n" + "=" * 62)
    print("示例 2：边界情况")
    print("=" * 62)
    cases = {
        "单点":            [(1.0, 1.0)],
        "两点":            [(0.0, 0.0), (3.0, 4.0)],
        "三点共线":        [(0, 0), (1, 1), (2, 2)],
        "存在重合点":      [(5, 5), (7, 2), (5, 5)],
        "正方形四顶点":    [(0, 0), (0, 1), (1, 0), (1, 1)],
    }
    for name, cs in cases.items():
        d, a, b = closest_pair(cs)
        ds = "inf" if math.isinf(d) else f"{d:.6f}"
        print(f"  {name:<12} -> 距离 = {ds:<10} 点对 = ({a}, {b})")

    print("\n" + "=" * 62)
    print("示例 3：随机数据与暴力法对拍（正确性验证）")
    print("=" * 62)
    random.seed(20260918)
    ok = True
    for trial in range(300):
        n = random.randint(2, 120)
        pts = [(random.uniform(-1e3, 1e3), random.uniform(-1e3, 1e3))
               for _ in range(n)]
        d_fast, _, _ = closest_pair(pts)
        d_slow, _, _ = brute_closest_pair(pts)
        if not math.isclose(d_fast, d_slow, rel_tol=1e-12, abs_tol=1e-12):
            ok = False
            print(f"  [FAIL] trial={trial} n={n} fast={d_fast} slow={d_slow}")
            break
    print(f"  {'全部 300 组测试通过 ✓' if ok else '存在不一致 ✗'}")

    print("\n" + "=" * 62)
    print("示例 4：规模性能对比")
    print("=" * 62)
    import time
    for n in (2000, 8000, 30000):
        pts = [(random.uniform(-1e5, 1e5), random.uniform(-1e5, 1e5))
               for _ in range(n)]
        t0 = time.perf_counter(); d1, a1, b1 = closest_pair(pts)
        t1 = time.perf_counter()
        msg = "  (跳过)"
        if n <= 8000:
            t2 = time.perf_counter(); d2, _, _ = brute_closest_pair(pts)
            t3 = time.perf_counter()
            msg = f"暴力 {t3 - t2:8.4f}s 一致={math.isclose(d1, d2, rel_tol=1e-9)}"
        print(f"  n={n:>6}  分治 {t1 - t0:8.4f}s   {msg}")
        print(f"           最近距离 = {d1:.6f}  点对 = ({a1}, {b1})")


if __name__ == "__main__":
    if "--n" in sys.argv:
        # 简单压力测试入口
        n = int(sys.argv[sys.argv.index("--n") + 1])
        random.seed(0)
        pts = [(random.uniform(-1e6, 1e6), random.uniform(-1e6, 1e6))
               for _ in range(n)]
        import time
        t0 = time.perf_counter()
        d, a, b = closest_pair(pts)
        print(f"n={n} 耗时 {time.perf_counter() - t0:.4f}s "
              f"最近距离={d:.6f} 点对=({a}, {b})")
    else:
        _demo()
```

## 第四部分：复杂度分析

### 时间复杂度

设 T(n) 为处理 n 个点的递归耗时。逐段统计：

| 阶段 | 代价 | 说明 |
|---|---|---|
| Divide | O(1) | 数组切片定位中点（切片本身计入合并项） |
| 拆分 Py | O(n) | 一趟扫描 + 哈希集合成员判定 |
| 两次递归 | 2T(n/2) | 左右子问题规模各约 n/2 |
| Merge | O(n) | 构造 strip 为 O(n)；每个点至多向后比较 7 次 → O(7n) = O(n) |

**递推式：**

T(n) = Θ(1),                              n ≤ 3
T(n) = 2·T(n/2) + Θ(n),                   n > 3

**方法一：主定理（Master Theorem）**

对照 T(n) = a·T(n/b) + f(n)，其中 a=2, b=2, f(n)=Θ(n)。

n^(log_b a) = n^(log_2 2) = n¹ = n = Θ(f(n))

命中 **Case 2**（f(n) = Θ(n^(log_b a))），故：

T(n) = Θ(n^(log_b a) · log n) = Θ(n log n) ✓

**方法二：递归树展开（自证）**

第 i 层有 2^i 个规模为 n/2^i 的子问题，该层非递归工作量为：

2^i · c · (n / 2^i) = c·n

树高为 log₂ n（叶子处 n/2^i = 1），叶子数 n 个，每叶 Θ(1)。因此：

T(n) = Σ(i=0..log₂n-1) c·n + Θ(n) = c·n·log₂ n + Θ(n) = Θ(n log n)

**加上初始预排序** 2×O(n log n)，总体仍为：

**T(n) = Θ(n log n)**

> 补充说明：若不用「预排序 + 线性拆分 Py」的技巧，而每层都对子集重新按 y 排序，递推式会退化为 T(n)=2T(n/2)+Θ(n log n)，由主定理 Case 2 的推广得 T(n)=Θ(n log² n)。这正是本实现刻意维护双有序数组的原因。

### 空间复杂度

| 项目 | 用量 |
|---|---|
| 双份有序数组 `px` / `py` | O(n) |
| 递归每层的临时数组 `qx/rx/qy/ry/strip/left_ids` | 同一时刻沿一条递归路径共存，总量为 n + n/2 + n/4 + … < 2n = O(n) |
| 递归栈深度 | O(log n) |

**S(n) = Θ(n)**

（若改用下标区间 + 单一辅助数组做原地归并式划分，可稳定保持 Θ(n) 且常数更小。）

## 第五部分：正确性证明的关键 —— 为什么带状区域内每个点只需检查后面最多 7 个点

### 记号与前提

- δ = min(δ₁, δ₂)，即左右两半内部最近距离的较小者。
- 分割线 L: x = mid_x。
- 带状区域 S = {p : |p.x − mid_x| < δ}，并按 y 升序排列。
- 反设存在跨线点对 (p, q) 使 d(p, q) < δ（这是唯一可能优于 δ 的情形）。

### 引理 1（δ 的传递性 / 打包性质）

**同侧任意两点距离 ≥ δ。**

证明：若 p、q 同在左半且 d(p,q) < δ ≤ δ₁，则与 δ₁ 是左半内部**最小**距离矛盾。右半同理。（重合点情形已在预处理中特判为 0。）∎

### 引理 2（候选点必落在 δ×2δ 矩形内）

设 p 在左半、q 在右半，且 d(p,q) < δ。则：

|p.x − q.x| ≤ d(p,q) < δ，且 |p.y − q.y| ≤ d(p,q) < δ

于是 q 必落在以 p 为中心、宽 δ、高 2δ 的开矩形内——具体地，q 位于 p 右侧、横向不越过 mid_x + δ、纵向上下各 δ 之内。

因此我们只需回答一个问题：**这个矩形内最多能塞多少个来自 S 的点？**

### 引理 3（核心计数：δ×2δ 矩形内至多 8 个点）

将矩形划分为 2×4 共 **8 个** 小正方形，每个小正方形边长为 δ/2。

- 每个小正方形的**对角线长度** = (δ/2)·√2 = (√2/2)·δ ≈ 0.707 δ < δ。
- 由引理 1，**同侧**两点距离 ≥ δ。而一个小正方形内若有两个点，它们距离 < δ，故这两个点必分属不同侧。
- 又因为整个矩形横跨分割线两侧，且小正方形完全落在某一侧（划分对齐 mid_x），所以**每个小正方形内至多容纳 1 个点**——否则同格两点距离 < δ，与“该格所在一侧的内部最近距离 ≥ δ”矛盾。

于是该 δ×2δ 矩形内**至多有 8 个点**。扣除 p 自身所在的格（p 正是被考察点），矩形内除 p 之外**至多 7 个候选点**。∎

### 引理 4（“后面 7 个”而非“任意 7 个”）

序列 S 按 y 升序排列。对固定 p = S[i]，任何满足 d(p,q) < δ 的候选 q 必有：

p.y − δ < q.y < p.y + δ

而在 S 中排在 p **前面**（y 更小）的那些点，会在它们各自的轮次中被检查到（对称性：距离是对称的）。所以我们只需向 p 的**后方**看，且只需看到 q.y − p.y < δ 为止。

由引理 3，p 上方那个 δ×2δ 半矩形（即 p.y ≤ y < p.y + δ 的部分）中的点数受 7 约束——等价地，**在按 y 排序的序列中，p 之后至多 7 个点**可能与其距离小于 δ。第 8 个之后的点纵坐标差必然 ≥ δ，距离也必然 ≥ δ，可直接排除。

### 定理（合并步骤不遗漏最优解）

设 (p*, q*) 为全局最近点对，距离 d* < δ。

1. 它必跨分割线（否则一侧内部有更近点对，与 δ 定义矛盾）；
2. 由引理 2，p*、q* 都在带状区域 S 中；
3. 不妨设 p* 在 S 中先出现，由引理 3、4，q* 必在 p* 之后不超过 7 个位置内；
4. 算法对该窗口内每一对都精确计算距离并更新 δ。

故 (p*, q*) 一定被枚举到，δ 会被更新为 d*。**合并步骤无遗漏。** ∎

### 归纳完成整体正确性

- **基础**：n ≤ 3 时暴力枚举所有 C(n,2) 对，结论显然正确。
- **归纳假设**：算法对所有规模 < n 的点集返回正确的最近距离。
- **归纳步**：规模 n 时，左右递归各返回本侧正确答案 δ₁、δ₂；合并步骤依据上述定理穷尽了所有可能优于 min(δ₁, δ₂) 的跨线点对。三者取最小即为全局答案。

由数学归纳法，算法对任意 n 正确。结合第四部分的 Θ(n log n) 复杂度，得到所要求的最优分治解。

### 常见变体提示

- 三维空间中，同样的打包论证给出每个点需检查**后面至多 15 个点**（把立方体划成小格计数），递推式变为 T(n)=2T(n/2)+Θ(n) 仍为 Θ(n log n)。
- 若改用“每格放多点”的松散论证会得到常数 15 或 16，但 7 是最紧的经典界（Shamos–Hoey, 1975；Bentley 1984 的扫掠版本进一步简化实现）。
