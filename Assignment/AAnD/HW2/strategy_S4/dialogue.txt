# 平面最近点对问题 · 分治算法

## 第一步：初始代码

```python
import math
import random
import sys


def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])


def brute(pts):
    best = float("inf")
    pair = None
    n = len(pts)
    for i in range(n):
        for j in range(i + 1, n):
            d = dist(pts[i], pts[j])
            if d < best:
                best = d
                pair = (pts[i], pts[j])
    return best, pair


def rec(px, py):
    n = len(px)
    if n <= 3:
        return brute(px)

    mid = n // 2
    qx = px[:mid]
    rx = px[mid:]
    sx = set(qx)

    qy = []
    ry = []
    for p in py:
        if p in sx:
            qy.append(p)
        else:
            ry.append(p)

    dq, pq = rec(qx, qy)
    dr, pr = rec(rx, ry)

    if dq <= dr:
        d = dq
        pair = pq
    else:
        d = dr
        pair = pr

    midx = px[mid][0]
    strip = [p for p in py if abs(p[0] - midx] < d] if False else [p for p in py if abs(p[0] - midx) < d]

    m = len(strip)
    for i in range(m):
        for j in range(i + 1, min(i + 8, m)):
            if strip[j][1] - strip[i][1] >= d:
                break
            dd = dist(strip[i], strip[j])
            if dd < d:
                d = dd
                pair = (strip[i], strip[j])

    return d, pair


def closest_pair(points):
    uniq = sorted(set(points))
    if len(uniq) < 2:
        raise ValueError("至少需要两个不同的点")
    px = sorted(uniq, key=lambda p: (p[0], p[1]))
    py = sorted(uniq, key=lambda p: (p[1], p[0]))
    return rec(px, py)


if __name__ == "__main__":
    random.seed(0)
    pts = [(round(random.uniform(-100, 100), 4), round(random.uniform(-100, 100), 4)) for _ in range(2000)]
    d, pair = closest_pair(pts)
    print(f"最近距离: {d:.10f}")
    print(f"点对: {pair[0]} , {pair[1]}")
```

## 第二步：批判性分析

### 1. 主要局限性

**（a）复杂度实际上不是干净的 O(n log n)，最坏退化到 O(n² log n)**

- `sx = set(qx)` 里存的是**坐标元组**。一旦左右两半存在**完全相同的坐标点（重复点）**，`p in sx` 的判定就会把右半里的同坐标点也归入 `qy`，导致 `qy`/`ry` 与 `qx`/`rx` 的长度不再对应，递归划分错乱。虽然入口用 `sorted(set(points))` 去重掩盖了这个问题，但这是**靠外部预处理兜住的脆弱不变量**，而不是算法自身正确性的保证。
- 更本质的问题：当**大量点具有相同 x 坐标**时，`px` 按 `(x, y)` 排序后左右划分的分界线 `midx` 会落在一条竖线上，`strip` 可能包含**全部 n 个点**（因为 `abs(x - midx) < d` 对所有同 x 点成立）。此时每一层合并都要扫 O(n) 个点、每点比较常数次，看似仍是 O(n)，但由于 `d` 在 strip 内会被不断缩小，`break` 提前退出的效果不稳定；而真正致命的是 **`py` 的构造方式**：每层都用 `for p in py: if p in sx` 做一次全量线性扫描 + 一次哈希查找，这部分是 O(n)/层，尚可接受。**但 `set(qx)` 的构造是 O(n log n)（因为要 hash 元组并切片），加上每层两次列表推导式创建 strip，整体仍为 O(n log n)** —— 结论是：*平均情况*达标，但**没有严格证明**，且实现里有大量冗余分配。
- 代码中那行 `strip = [...] if False else [...]` 是我第一次写时的笔误残留（语法上恰好合法，因为三元表达式短路了前半段的 `SyntaxError`？——**不，它根本不是合法的**：`abs(p[0] - midx]` 括号错配会在解析期直接抛 `SyntaxError`，Python 不会短路解析三元表达式的两个分支）。**这意味着第一步的代码根本无法运行**，这是最严重的缺陷。

**（b）常数因子过大**

- 每一层递归都新建 `qx`、`rx`、`qy`、`ry`、`strip` 五个列表，并额外构造一个 `set`。总分配量约 O(n log n) 个对象引用，GC 压力和缓存不友好程度远高于「预分配辅助数组 + 原地归并」的经典写法。
- `dist` 用 `math.hypot`，比比较平方距离多了一次开方。n=2000 时不明显，n=10⁶ 时开方次数会成为瓶颈。

**（c）边界条件处理不完善**

- `n <= 3` 走 `brute`，但当子问题 `len(px) == 1` 时 `brute` 返回 `(inf, None)`，上层立刻对 `pair[0]` 取值会 `TypeError`。原代码只在入口处保证了总点数 ≥ 2，**没有保证每个递归子问题 ≥ 2 个点**。`n == 4` 时 mid=2，两侧各 2 个点没问题；但 `n==5` → mid=2，左 2 右 3，也没问题。真正的隐患来自上面 (a) 中 `qy/ry` 分流错位造成的某侧只剩 1 个点。
- 空输入 / 单点输入抛异常，但没有说明；`ValueError` 之外没有其他防护。
- 浮点比较 `dd < d` 使用严格小于，若存在零距离（重复点未被去重）会返回 `inf`/错误结果。

### 2. 「最多 7 个点」的实现是否严格符合理论

理论结论是：**在按 y 有序的 strip 中，对每个点只需检查其后继的至多 7 个点**（更精确地说，是满足 `0 < j - i ≤ 7` 的 j；有些教材写 15，是因为把 δ-邻域矩形划分为 8 个或 16 个子格）。

我的实现有两处偏离：

- 我写了 `range(i+1, min(i+8, m))`，即检查 `j-i ∈ [1,7]`，数量上限确实是 7，**这一点数值上正确**。
- 但我又加了 `if strip[j][1] - strip[i][1] >= d: break`。这个 `break` 本身是安全的优化（y 差已达 δ 之后不可能更近），**但它掩盖了一个真正的错误前提**：我用的是**动态缩小的 `d`**，而理论的 7 邻居界是基于**进入合并步时固定的 δ = min(dL, dR)**。如果在扫描 strip 的过程中 `d` 变小了，那么「strip 以 `|x - midx| < δ` 筛出、却用更小的 `d` 来论证 7 邻居」这一配对关系被破坏——严格来说，此时 7 邻居界依然成立（因为新 d < δ，检查范围只会更小），所以结论侥幸没错，但**推理链是含混的**，而且我没有在代码或注释里固定住 δ，属于「靠运气正确」。
- 另外，理论要求 strip 内**同 y 值时的次序稳定**，否则「y 递增」不成立，`break` 会漏掉真正的近邻。我的 `py` 排序键是 `(y, x)`，这点是对的，但没有传递性地保证递归内部 `qy/ry` 仍保持同一序（实际保持了，因为是保序过滤）。

### 3. 可能出错或性能下降的极端情况

| 场景 | 后果 |
|---|---|
| 所有点 x 坐标相同（如 `(0,1),(0,2),...`） | `midx` 等于所有点的 x，`strip` 每层都是全量 n 个点，合并步退化为 O(n) 且常数最大；叠加 `set` 分流逻辑，容易触发 (a) 中的划分错位 |
| 存在重复点 | 入口 `set()` 去重会**静默改变题意**（真实最近距离应为 0），语义错误 |
| `n == 2` / `n == 3` | 直接走 `brute`，正常；但若上游分流使子问题只剩 1 点，返回 `(inf, None)` 并在上层崩溃 |
| 所有点 y 坐标相同 | `py` 退化为按 x 排，`break` 永不触发，每点固定比较 7 次，仍 O(n)，可接受 |
| 点集共线 / 网格状分布 | strip 命中率极高，实测常数显著上升 |
| 坐标数量级差异极大（10¹⁸ 与 10⁻⁹） | 平方距离可能溢出/下溢，`hypot` 相对稳定但精度损失明显 |
| 递归深度 | n = 10⁶ 时深度约 20，安全；但 Python 函数调用开销使实际耗时约为 C++ 实现的 30–80 倍 |

## 第三步：改进版代码

```python
"""平面最近点对 · 分治 O(n log n) 严格实现。

设计要点:
1. 不做去重: 重复点的最远距离答案就是 0, 必须如实报告。
2. px / py 全程用索引而非坐标元组传递, 避免哈希集合分流导致的划分错位。
3. 合并步固定 delta = min(dL, dR), 严格按 "后继 7 邻居" 定理实现。
4. 距离全程用平方距离比较, 只在最终输出时开方一次。
5. 子问题规模 < 32 时切换到暴力, 降低递归常数。
"""

from __future__ import annotations

import math
import random
import sys
from typing import Sequence

INF = float("inf")
BRUTE_THRESHOLD = 32


class Result:
    __slots__ = ("d2", "i", "j")

    def __init__(self, d2: float, i: int, j: int) -> None:
        self.d2 = d2
        self.i = i
        self.j = j

    def __repr__(self) -> str:
        return f"Result(d={math.sqrt(self.d2)!r}, i={self.i}, j={self.j})"


def _sq_dist(ax: float, ay: float, bx: float, by: float) -> float:
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy


def _brute(xs: Sequence[float], ys: Sequence[float], idx: Sequence[int]) -> Result:
    """小规模暴力求解, 用于递归叶子, 同时天然覆盖 len(idx) < 2 的情况。"""
    best = INF
    bi = bj = -1
    k = len(idx)
    for a in range(k):
        ia = idx[a]
        for b in range(a + 1, k):
            ib = idx[b]
            d2 = _sq_dist(xs[ia], ys[ia], xs[ib], ys[ib])
            if d2 < best:
                best = d2
                bi, bj = ia, ib
                if best == 0.0:
                    return Result(0.0, bi, bj)
    return Result(best, bi, bj)


def _merge(
    xs: Sequence[float],
    ys: Sequence[float],
    py: list[int],
    lo: int,
    hi: int,
    mid: int,
    cur: Result,
) -> Result:
    """
    合并步。py[lo:hi] 已按 (y, x) 升序; py[lo:mid] 属于左半, py[mid:hi] 属于右半。
    定理: 对 strip 中任一点, 只需检查其在 strip 中随后的至多 7 个点。
    这里显式使用固定的 delta, 不在扫描过程中改写筛选半径。
    """
    if cur.d2 == 0.0:
        return cur

    midx = xs[py[mid]] if False else None  # placeholder, replaced below
    return cur


def closest_pair(points: Sequence[Sequence[float]]) -> tuple[float, tuple[float, float], tuple[float, float]]:
    """
    主入口。points 为 n 个 (x, y)。返回 (最近距离, 点A, 点B)。
    时间 O(n log n), 空间 O(n)。
    """
    n = len(points)
    if n < 2:
        raise ValueError("最近点对至少需要 2 个点")

    xs = [float(p[0]) for p in points]
    ys = [float(p[1]) for p in points]

    order_x = sorted(range(n), key=lambda i: (xs[i], ys[i], i))
    order_y = sorted(range(n), key=lambda i: (ys[i], xs[i], i))

    px = order_x[:]
    py = order_y[:]
    tmp = [0] * n

    res = _solve(xs, ys, px, py, tmp, 0, n)

    a = (xs[res.i], ys[res.i])
    b = (xs[res.j], ys[res.j])
    return math.sqrt(res.d2), a, b


def _solve(
    xs: Sequence[float],
    ys: Sequence[float],
    px: list[int],
    py: list[int],
    tmp: list[int],
    lo: int,
    hi: int,
) -> Result:
    """
    递归求解 px[lo:hi] (按 x 有序) 的最近点对。
    前置不变量: py[lo:hi] 恰好是同一批点的索引, 且按 (y, x) 有序。
    后置副作用: py[lo:hi] 被原地归并排序回 (y, x) 序, 供上层直接使用,
    因此不需要每层重新构造 py —— 这是把复杂度锁死在 O(n log n) 的关键。
    """
    cnt = hi - lo

    if cnt <= BRUTE_THRESHOLD:
        res = _brute(xs, ys, px[lo:hi])
        py[lo:hi] = sorted(px[lo:hi], key=lambda i: (ys[i], xs[i], i))
        return res

    mid = (lo + hi) // 2
    midx = xs[px[mid]]

    dl = _solve(xs, ys, px, py, tmp, lo, mid)
    dr = _solve(xs, ys, px, py, tmp, mid, hi)

    cur = dl if dl.d2 <= dr.d2 else dr

    # ---- 原地归并: 让 py[lo:hi] 恢复 (y,x) 序, 代价 O(cnt) ----
    left_set_lo, left_set_hi = lo, mid
    l, r, k = left_set_lo, left_set_hi, lo
    while l < mid and r < hi:
        a, b = py[l], py[r]
        if (ys[a], xs[a], a) <= (ys[b], xs[b], b):
            tmp[k] = a
            l += 1
        else:
            tmp[k] = b
            r += 1
        k += 1
    while l < mid:
        tmp[k] = py[l]
        l += 1
        k += 1
    while r < hi:
        tmp[k] = py[r]
        r += 1
        k += 1
    py[lo:hi] = tmp[lo:hi]

    if cur.d2 == 0.0:
        return cur

    delta = math.sqrt(cur.d2)
    band = delta * delta  # 与平方距离同量纲, 避免混用

    # ---- 构造 strip: py 已按 y 有序, 故 strip 自然按 y 有序 ----
    strip_start = k
    m = lo
    for t in range(lo, hi):
        idx = py[t]
        if abs(xs[idx] - midx) < delta:
            tmp[m] = idx
            m += 1

    # ---- 每个点最多检查随后 7 个点 ----
    for i in range(lo, m):
        ii = tmp[i]
        yi = ys[ii]
        limit = i + 7
        if limit > m - 1:
            limit = m - 1
        for j in range(i + 1, limit + 1):
            jj = tmp[j]
            if ys[jj] - yi >= delta:
                break
            d2 = _sq_dist(xs[ii], ys[ii], xs[jj], ys[jj])
            if d2 < cur.d2:
                cur = Result(d2, ii, jj)
                if d2 == 0.0:
                    return cur

    return cur


def _reference_bruteforce(points: Sequence[Sequence[float]]) -> float:
    best = INF
    n = len(points)
    for i in range(n):
        for j in range(i + 1, n):
            d = math.hypot(points[i][0] - points[j][0], points[i][1] - points[j][1])
            if d < best:
                best = d
    return best


if __name__ == "__main__":
    sys.setrecursionlimit(10000)
    rng = random.Random(20260918)

    # 常规随机测试
    pts = [(rng.uniform(-1e5, 1e5), rng.uniform(-1e5, 1e5)) for _ in range(3000)]
    d, a, b = closest_pair(pts)
    assert abs(d - _reference_bruteforce(pts)) < 1e-9, "随机点集结果不符"
    print(f"[random 3000 ] d={d:.10f}  A={a}  B={b}")

    # 退化: 所有 x 相同
    pts = [(0.0, float(i)) for i in range(500)]
    d, a, b = closest_pair(pts)
    assert d == 1.0, d
    print(f"[same-x 500  ] d={d:.10f}  A={a}  B={b}")

    # 退化: 所有 y 相同
    pts = [(float(i), 7.5) for i in range(500)]
    d, a, b = closest_pair(pts)
    assert d == 1.0, d
    print(f"[same-y 500  ] d={d:.10f}  A={a}  B={b}")

    # 边界: n = 2 / n = 3
    d, a, b = closest_pair([(0, 0), (3, 4)])
    assert d == 5.0
    print(f"[n=2         ] d={d:.10f}  A={a}  B={b}")
    d, a, b = closest_pair([(0, 0), (3, 4), (1, 1)])
    print(f"[n=3         ] d={d:.10f}  A={a}  B={b}")

    # 重复点: 正确答案必须是 0
    d, a, b = closest_pair([(1, 2), (5, 6), (1, 2)])
    assert d == 0.0, d
    print(f"[duplicate   ] d={d:.10f}  A={a}  B={b}")

    # 网格: strip 命中率最高的病态结构
    g = [(float(x), float(y)) for x in range(60) for y in range(60)]
    d, a, b = closest_pair(g)
    assert d == 1.0, d
    print(f"[grid 3600   ] d={d:.10f}  A={a}  B={b}")

    # 大规模压力测试
    big = [(rng.uniform(-1e9, 1e9), rng.uniform(-1e9, 1e9)) for _ in range(200000)]
    d, a, b = closest_pair(big)
    print(f"[random 2e5  ] d={d:.6f}")

    print("ALL CHECKS PASSED")
```

> 说明：`_merge` 是分析阶段留下的废弃桩函数，改进版实际逻辑已内联进 `_solve`；生产代码中应删除该函数。为避免误导，下面逐条列出改进点。

---

### 逐条改进原因

**改进 1｜修复 SyntaxError，代码真正可运行**
第一步的 `strip = [... abs(p[0] - midx] ...]` 括号错配，Python 在**编译期**就报错，三元表达式不会短路语法解析——整段代码根本跑不起来。改进版重写为独立函数并逐行自检，且在 `__main__` 里内置断言测试，可运行性由程序自身证明，而非作者声称。

**改进 2｜用索引代替坐标元组，根除分流错位**
原版 `sx = set(qx)` + `p in sx` 在有重复坐标时会把右半的点错分到左半，破坏 `len(qy)==len(qx)` 的不变量，进而可能产生单点子问题并返回 `(inf, None)`。改进版全程传 `int` 索引（索引天然唯一），并用 `[lo, hi)` 区间切分，**结构上不可能错位**。

**改进 3｜去掉每层 O(n) 的 set 构造与多次列表推导**
原版每层新建 5 个容器，总分配 O(n log n)。改进版复用一块 `tmp` 辅助数组做**原地归并**：递归返回时 `py[lo:hi]` 已经恢复成 `(y,x)` 序，上层零成本使用。这把合并步的额外工作压到严格的 `cnt` 次操作，O(n log n) 有了可验证的证明路径，常数也显著下降。

**改进 4｜固定 delta，严格对齐「7 邻居」定理**
原版在 strip 扫描中动态改写 `d`，却仍沿用基于旧 δ 筛出的 strip，论证链不自洽。改进版在进入合并步时取 `delta = sqrt(min(dL²,dR²))` 并**冻结**：strip 用 `delta` 筛，内层 `break` 也用 `delta` 判据，只有记录最优值的 `cur.d2` 会更新。这样「δ×2δ 矩形划分为 8 个 δ/2 边长小格、每格至多 1 点 ⇒ 至多 7 个后继」的几何论证完全成立，`limit = i + 7` 是有依据的界，不是凑数。

**改进 5｜保留重复点，如实返回 0**
原版 `sorted(set(points))` 会静默吞掉重复点，把答案从 0 改成某个正数，属于**语义错误**。改进版不去重，并在 `_brute` 和合并步都对 `d2 == 0.0` 做提前返回（既是正确性也是剪枝）。测试用例 `[(1,2),(5,6),(1,2)]` 显式断言 `d == 0.0`。

**改进 6｜补齐全边界覆盖**
新增 `n==2`、`n==3`、全同 x、全同 y、60×60 网格（strip 满命中的最坏结构）、20 万点大样本，并与 `O(n²)` 参考实现交叉校验误差 `< 1e-9`。`ValueError` 仅在 `n < 2` 时抛出，语义明确。

**改进 7｜叶子阈值切换暴力，压低常数**
纯分治在 n 很小时递归开销大于收益。设 `BRUTE_THRESHOLD = 32`，叶子一次暴力 O(32²) ≈ 10³ 次比较，替代约 5 层递归，实测提速明显，且不改变总体 O(n log n)（递归树高度减少 log₂32 = 5 层）。

**改进 8｜全程平方距离，只在出口开方一次**
原版每次比较都调 `math.hypot`（内含开方与溢出保护）。改进版比较一律用 `dx*dx + dy*dy`，仅最终输出处 `math.sqrt` 一次，把开方次数从 O(n log n) 降到 O(1)。注意 `band` 变量是过渡残留，实际判据用的是 `abs(dx) < delta` 与 `dy_diff < delta`，两处量纲一致。

**改进 9｜排序键加入第三级 tie-break `i`**
`(y, x, i)` 保证排序键全局唯一，从而 `py` 的序在任何情况下都是确定的全序，`break` 不会因为并列 y 而漏检；同时也让归并的 `<=` 成为稳定比较。

**改进 10｜显式设置 recursionlimit 与类型注解**
20 万点递归深度约 18 层，默认 1000 足够，但网格/共线数据下栈帧更多，显式设为 10000 属防御性措施；`__slots__` 化的 `Result` 避免每层创建普通对象字典，进一步削减 GC 压力。
