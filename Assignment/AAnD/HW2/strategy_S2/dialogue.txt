# 平面最近点对问题：分治算法完整推理与实现

## 一、算法总体思路

暴力枚举所有点对需要 O(n²)。分治的核心想法是：**把点集按 x 坐标切成左右两半，递归求各自内部的最近距离，然后只需要高效处理“跨分界线”的点对**。

设 `dL` = 左半平面内部最近距离，`dR` = 右半平面内部最近距离，`δ = min(dL, dR)`。那么全局答案只有两种可能：① 完全在某一侧（已经被递归覆盖），② 两点分居两侧（需要在合并时检查）。所以合并步骤只需找出**跨侧且距离 < δ 的点对**。

---

## 二、四个问题的逐步推理

### 问题 1：Divide − Conquer − Combine 三步骤分别是什么？

**Divide（分解）**
先把点集按 x 坐标排序（预处理一次，全局复用），取中位数点 `mid = P[n//2]`，用一条竖直线 `x = mid.x` 把点集划成左右两半 `P[lo..mid]` 和 `P[mid+1..hi]`，规模各约 n/2。

**Conquer（解决）**
递归地在左右两半上求解同一问题，得到 `dL` 和 `dR`。递归边界：当子问题点数 ≤ 3 时，直接暴力两两比较（O(1)），同时把这个小子集按 y 排序返回。

**Combine（合并）**
令 `δ = min(dL, dR)`。只有满足 `|x - mid.x| < δ` 的点才可能与另一侧的点构成更近的点对，把这些点收集成**带状区域 strip**。把 strip 内的点**按 y 坐标排序**，对每个点只向后检查常数个邻居即可判定是否存在距离 < δ 的跨侧点对。若找到更小距离则更新 δ。

> 关键工程细节：为了让整体复杂度达到 O(n log n)，strip 的 y 有序不能每次重新排序，而要在递归返回时像归并排序一样**由左右两个已按 y 有序的序列合并得到**（见下方代码实现）。

---

### 问题 2：为什么合并步骤只需要检查带状区域（strip）内的点？

反证法。假设存在一对点 `(p, q)`，其中 `p` 在左侧、`q` 在右侧，且它们是全平面最近点对，即 `dist(p,q) < δ`。

由欧氏距离的性质，水平方向的差不会超过总距离：

```
|p.x − q.x| ≤ dist(p, q) < δ
```

而分界线 `x = x_mid` 位于 p 与 q 之间（p 在左、q 在右），因此：

```
|p.x − x_mid| ≤ |p.x − q.x| < δ
|q.x − x_mid| ≤ |p.x − q.x| < δ
```

也就是说 **p 和 q 到分界线的水平距离都严格小于 δ**，二者必然都落在宽度为 `2δ` 的竖直带 `[x_mid − δ, x_mid + δ]` 内。

逆否命题即：任何横坐标离分界线 ≥ δ 的点，它与另一侧任意点的距离必然 ≥ δ，不可能打败当前最优解，可以直接排除。这就把候选集从 O(n²) 对压缩到了 strip 内部的点对。

---

### 问题 3：为什么 strip 内每个点最多只需检查 7 个后续点？数学依据是什么？

这是本算法的经典“**δ/2 × δ/2 网格装箱论证**”（packing argument）。

**几何设置。** 取 strip 中一点 `p`，考虑它之后 y 坐标比它大、且不超过 `p.y + δ` 的点 —— 因为一旦 `q.y − p.y ≥ δ`，就有 `dist(p,q) ≥ δ`，不必再看。所以候选点全部落在以 p 为中心向上延伸的矩形里：宽 `2δ`（strip 宽度）、高 `δ`。

**细分网格。** 把这个 `2δ × δ` 的矩形用平行线划分成 `8` 个 `δ/2 × δ/2` 的小方格（横向 4 格、纵向 2 格）。每个小方格的**对角线长度为**：

```
√((δ/2)² + (δ/2)²) = (δ/2)·√2 = (√2/2)·δ ≈ 0.707 δ < δ
```

**同格互斥。** 若某小方格内落入两个点 A、B，则 `dist(A,B) < δ`。但这与 δ 的定义矛盾吗？分情况：
- 若 A、B 在同一侧 → 与该侧递归结果 `dL` 或 `dR` ≥ δ 矛盾；
- 若 A、B 在不同侧 → 说明我们已经找到了比 δ 更近的跨侧点对，此时 δ 会被立即更新变小，论证对新 δ 重新成立。

因此在“当前 δ 已经是最优下界”的前提下，**每个小方格内至多只能有一个点**。

**结论。** 8 个格子最多容纳 8 个点，去掉 p 自己占的那一格，p 后面最多还有 **7 个**候选点。所以按 y 排序后，对每个点只需向后扫 `j = i+1 … i+7` 并保证 `strip[j].y − strip[i].y < δ` 即可，这一步是 O(n) 的线性扫描。

> 补充说明：不同教材写 “7” 或 “15”，取决于矩形取 `2δ × δ`（→8 格，检查 7 个后继）还是保守地取 `2δ × 2δ`（→更多格）。标准结论是 **7**，实践中循环写成 7 或 8 都不影响正确性（多比较几个点只是常数开销）。

---

### 问题 4：整体时间复杂度为什么是 O(n log n)？

逐层统计代价：

| 步骤 | 单趟代价 |
|---|---|
| 初始按 x 排序 | O(n log n)，只做一次 |
| Divide：取中点切分 | O(1) |
| Conquer：两个子问题 | `2T(n/2)` |
| Combine：合并出 y 有序序列（归并） | O(n) |
| Combine：strip 构造 + 每点常数次比较 | O(n) |

于是递推关系为：

```
T(n) = 2·T(n/2) + O(n),   T(1) = O(1)
```

由**主定理（Master Theorem）Case 2**：`a=2, b=2, f(n)=Θ(n)`，`n^{log_b a} = n^{log_2 2} = n¹ = Θ(f(n))`，故 `T(n) = Θ(n log n)`。

也可以直观理解：递归树共 `log n` 层，每层所有子问题的合并工作量加起来恰好是 O(n)（因为每层的点总数仍是 n），所以总计 `O(n) × O(log n) = O(n log n)`。

**必须避免的退化写法**：如果在每一层递归里都对 strip 重新做一次 `sort(key=y)`，递推会变成 `T(n) = 2T(n/2) + O(n log n)`，主定理 Case 2 的对数因子叠加，结果退化为 `O(n log² n)`。下面的实现采用“自底向上归并 y 有序数组”的正确写法。

空间复杂度：需要辅助数组做归并，O(n)。

## 三、完整代码实现

```python
"""
平面最近点对问题 —— 分治算法
时间复杂度: O(n log n)
空间复杂度: O(n)

设计要点:
  1. 点集预先按 x 排序，全程不再重排 -> Divide 是 O(1)
  2. 递归函数返回时, px[lo..hi] 已被原地整理成按 y 有序 -> Combine 是 O(n) 归并
     (避免了每层 sort(key=y) 导致的 O(n log^2 n) 退化)
  3. strip 内利用 "8 格装箱" 结论, 每个点最多向后检查 7 个点
"""

import math
import random
from typing import List, Tuple

Point = Tuple[float, float]


def _dist(a: Point, b: Point) -> float:
    """欧几里得距离（用 hypot 避免中间量溢出/精度损失）"""
    return math.hypot(a[0] - b[0], a[1] - b[1])


class ClosestPairSolver:
    def __init__(self, points: List[Point]):
        if len(points) < 2:
            raise ValueError("至少需要 2 个点才能构成点对")
        # px: 按 x 升序（x 相同则按 y），递归过程中会被改写成按 y 有序
        self.px = sorted(points, key=lambda p: (p[0], p[1]))
        self.tmp = [None] * len(self.px)      # 归并用的辅助数组，只分配一次
        self.best_d = math.inf
        self.best_pair: Tuple[Point, Point] = None

    # ---------------- 核心分治 ----------------
    def solve(self) -> Tuple[float, Tuple[Point, Point]]:
        self._rec(0, len(self.px) - 1)
        return self.best_d, self.best_pair

    def _rec(self, lo: int, hi: int) -> None:
        """
        递归求解 px[lo..hi] 内部最近点对。
        前置条件: 调用前 px[lo..hi] 按 x 有序。
        后置条件: 返回时 px[lo..hi] 已变为按 y 有序（供上层归并使用）。
        """
        n = hi - lo + 1

        # ---- 递归边界: 规模 <= 3 直接暴力, 再手动按 y 排好 ----
        if n <= 3:
            for i in range(lo, hi + 1):
                for j in range(i + 1, hi + 1):
                    d = _dist(self.px[i], self.px[j])
                    if d < self.best_d:
                        self.best_d = d
                        self.best_pair = (self.px[i], self.px[j])
            # 插入排序, 规模常数, 不影响整体复杂度
            for i in range(lo + 1, hi + 1):
                k = i - 1
                v = self.px[i]
                while k >= lo and self.px[k][1] > v[1]:
                    self.px[k + 1] = self.px[k]
                    k -= 1
                self.px[k + 1] = v
            return

        mid = (lo + hi) // 2
        mid_x = self.px[mid][0]          # 必须在递归改写 px 之前记录分割线位置

        # ---- Conquer: 先递归左半, 再递归右半 ----
        # 注意: 左递归结束后 px[lo..mid] 变成按 y 有序, 但元素集合不变,
        #       仍然全部是 x <= mid_x 的那批点, 所以右递归区间 px[mid+1..hi] 依然合法。
        self._rec(lo, mid)
        self._rec(mid + 1, hi)

        # ---- Combine 第一步: 检查跨分界线的候选点 ----
        # 此时 best_d 已经是 min(dL, dR)（全局维护的当前最优下界）
        delta = self.best_d

        # 左右两半现在【已经按 y 有序】，直接双指针归并出整个区间的 y 有序序列
        # 归并的同时，把落在 strip 内的点记录下来 —— 这样 strip 天然按 y 有序，
        # 无需额外排序，是本实现维持 O(n log n) 的关键。
        i, j, k = lo, mid + 1, lo
        strip_start = lo                  # strip 段将被放到 tmp 的开头部分
        while i <= mid and j <= hi:
            if self.px[i][1] <= self.px[j][1]:
                self.tmp[k] = self.px[i]
                i += 1
            else:
                self.tmp[k] = self.px[j]
                j += 1
            k += 1
        while i <= mid:
            self.tmp[k] = self.px[i]
            i += 1
            k += 1
        while j <= hi:
            self.tmp[k] = self.px[j]
            j += 1
            k += 1

        # 把按 y 有序的结果写回 px[lo..hi]
        for t in range(lo, hi + 1):
            self.px[t] = self.tmp[t]

        # ---- 构造 strip（保持 y 有序）----
        strip = [p for p in self.px[lo:hi + 1] if abs(p[0] - mid_x) < delta]

        # ---- 每点最多向后检查 7 个点 ----
        m = len(strip)
        for a in range(m):
            # 内层最多走 7 步; 且一旦 y 差 >= delta 立刻 break（后面的点 y 更大，更远）
            for b in range(a + 1, min(a + 8, m)):
                if strip[b][1] - strip[a][1] >= self.best_d:
                    break
                d = _dist(strip[a], strip[b])
                if d < self.best_d:
                    self.best_d = d
                    self.best_pair = (strip[a], strip[b])
                    delta = d             # 同步收紧（strip 已按上面快照生成，不影响正确性）


def closest_pair(points: List[Point]) -> Tuple[float, Tuple[Point, Point]]:
    """对外接口：返回 (最近距离, (点A, 点B))"""
    return ClosestPairSolver(points).solve()


# ==================== 验证与演示 ====================

def brute_force(points: List[Point]) -> Tuple[float, Tuple[Point, Point]]:
    """O(n^2) 暴力参考实现，用于随机测试交叉校验"""
    best = math.inf
    pair = None
    n = len(points)
    for i in range(n):
        for j in range(i + 1, n):
            d = _dist(points[i], points[j])
            if d < best:
                best = d
                pair = (points[i], points[j])
    return best, pair


def self_test(iterations: int = 500) -> None:
    """随机压力测试：分治结果的距离必须与暴力枚举完全一致"""
    rng = random.Random(2026)
    for it in range(iterations):
        n = rng.randint(2, 200)
        pts = [(rng.uniform(-100, 100), rng.uniform(-100, 100)) for _ in range(n)]
        d1, p1 = closest_pair(pts)
        d2, p2 = brute_force(pts)
        assert math.isclose(d1, d2, rel_tol=1e-9, abs_tol=1e-9), \
            f"第{it}轮不一致: n={n}, {d1} vs {d2}"
        # 分治给出的那一对，其真实距离也必须等于最优值
        assert math.isclose(_dist(p1[0], p1[1]), d2, rel_tol=1e-9, abs_tol=1e-9)
    print(f"[OK] {iterations} 轮随机测试全部通过（分治 == 暴力）")


def demo() -> None:
    pts = [(2, 3), (12, 30), (40, 50), (5, 1), (12, 10), (3, 4),
           (50, 60), (1, 2), (9, 10), (30, 20)]

    d, (a, b) = closest_pair(pts)
    print("输入点集:", pts)
    print(f"最近距离 = {d:.6f}")
    print(f"最近点对 = {a}  <->  {b}")

    # 含重复点的退化情形
    d2, p2 = closest_pair([(1, 1), (1, 1), (5, 5)])
    print(f"\n重复点测试: 最近距离 = {d2}, 点对 = {p2}")

    # 大规模性能展示
    big = [(random.uniform(0, 1e6), random.uniform(0, 1e6)) for _ in range(200000)]
    import time
    t0 = time.perf_counter()
    db, pb = closest_pair(big)
    t1 = time.perf_counter()
    print(f"\n20 万点分治耗时 {t1 - t0:.2f}s, 最近距离 = {db:.6e}")


if __name__ == "__main__":
    self_test()
    print()
    demo()
```

## 五、实现中的三个易错点（对应上面的推理）

1. **`mid_x` 必须在递归调用之前保存。** 因为 `_rec` 返回时 `px[lo..hi]` 已被改写成按 y 有序，中位点的位置会漂移，事后再取 `px[mid][0]` 就错了。

2. **strip 必须借助“左右两半已按 y 有序 + 归并”来得到，不能在每层重新排序。** 这正是问题 4 中区分 `O(n log n)` 与 `O(n log² n)` 的唯一分水岭。

3. **左递归结束后仍可安全递归右半。** 看起来“px 被搞乱了”，但改写只改变顺序不改变元素归属：`px[lo..mid]` 里的点仍然是原来 x 较小的那一半，`px[mid+1..hi]` 同理，所以两次递归处理的点集划分始终正确。
