第一部分：算法思路

第二类斯特林数 S(n, k) 表示将 n 个不同的元素划分成 k 个非空且无序的集合的方案数。

递推关系的核心思想是考虑第 n 个元素的归属，分两种情况讨论：

第 n 个元素单独构成一个新集合：此时前 n−1 个元素需要被划分成 k−1 个集合，方案数为 S(n−1, k−1)。
第 n 个元素加入已有的某个集合：前 n−1 个元素已经被划分成 k 个集合（方案数 S(n−1, k)），第 n 个元素可以加入这 k 个集合中的任意一个，因此方案数为 k × S(n−1, k)。

根据加法原理，两者相加即得递推式：S(n, k) = k × S(n−1, k) + S(n−1, k−1)。

边界条件为：S(n, n) = 1（每个元素单独成一组）、S(n, 1) = 1（所有元素放入同一组）、当 k > n 或 k < 1 时 S(n, k) = 0。

算法采用自底向上的动态规划方法，构建一张二维表格，逐行填充，避免递归带来的重复计算。

第三部分：完整代码

def stirling(n: int, k: int) -> int:
    """
    计算第二类斯特林数 S(n, k)。
    
    递推关系: S(n, k) = k * S(n-1, k) + S(n-1, k-1)
    边界条件: S(n, n) = 1, S(n, 1) = 1, S(n, k) = 0 (k > n 或 k < 1)
    
    参数:
        n: 元素总数（非负整数）
        k: 集合数量（正整数）
    
    返回:
        将 n 个不同元素划分为 k 个非空无序集合的方案数
    """
    # 处理非法输入
    if k < 1 or k > n:
        return 0
    # 边界条件：每个元素单独成一组，或所有元素放入同一组
    if k == 1 or k == n:
        return 1

    # 创建 (n+1) x (k+1) 的二维 DP 表，初始值为 0
    dp = [[0] * (k + 1) for _ in range(n + 1)]

    # 自底向上填充 DP 表
    for i in range(1, n + 1):
        # j 只需遍历到 min(i, k)，因为当 j > i 时 S(i, j) = 0
        for j in range(1, min(i, k) + 1):
            if j == 1 or j == i:
                # 边界条件
                dp[i][j] = 1
            else:
                # 递推公式：S(i, j) = j * S(i-1, j) + S(i-1, j-1)
                dp[i][j] = j * dp[i - 1][j] + dp[i - 1][j - 1]

    return dp[n][k]

第四部分：复杂度分析

时间复杂度：O(n × k)

算法使用两层嵌套循环，外层遍历 i 从 1 到 n，内层遍历 j 从 1 到 min(i, k)。每个状态 dp[i][j] 的计算仅涉及一次乘法和一次加法（常数时间操作），因此总的时间复杂度为 O(n × k)。当 k 接近 n 时，复杂度退化为 O(n²)。

空间复杂度：O(n × k)

算法维护了一张大小为 (n+1) × (k+1) 的二维 DP 表，因此空间复杂度为 O(n × k)。

空间优化说明：由于递推式中 dp[i][j] 仅依赖于上一行（i−1）的两个相邻值 dp[i−1][j] 和 dp[i−1][j−1]，因此可以使用滚动数组或一维数组将空间复杂度优化至 O(k)。具体做法是从右向左更新一维数组，确保在计算 dp[j] 时 dp[j−1] 仍是上一轮的值。
