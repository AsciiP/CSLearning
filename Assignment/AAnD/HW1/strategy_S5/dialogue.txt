第一步：标准代码

def stirling2(n: int, k: int) -> int:
    """第二类斯特林数 S(n, k)：把 n 个不同元素划分成 k 个非空无序集合的方案数。
    递推：S(n,k) = k*S(n-1,k) + S(n-1,k-1)
    时间 O(nk)，空间 O(k)（滚动数组）
    """
    if n < 0 or k < 0 or k > n:
        return 0
    if k == 0:
        return 1 if n == 0 else 0

    dp = [0] * (k + 1)
    dp[0] = 1                     # S(0,0) = 1
    for i in range(1, n + 1):
        # 逆序更新，保证 dp[j-1] 仍是上一行（i-1）的值
        for j in range(min(i, k), 0, -1):
            dp[j] = j * dp[j] + dp[j - 1]
    return dp[k]

def stirling2_table(n: int):
    """返回完整的 (n+1) x (n+1) 三角表，便于教学调试与验证。"""
    S = [[0] * (n + 1) for _ in range(n + 1)]
    S[0][0] = 1
    for i in range(1, n + 1):
        for j in range(1, i + 1):
            S[i][j] = j * S[i - 1][j] + S[i - 1][j - 1]
    return S

第二步：教学反思（教师视角）

三个最可能让初学者困惑的地方

困惑一：递推式为什么是 k·S(n-1,k) + S(n-1,k-1)，而不是别的系数？
初学者往往死记公式，无法解释系数 k 的来源。其核心在于“第 n 个元素去哪了”：将前 n−1 个元素分好 k 个盒子后，第 n 个元素要么加入已有的 k 个盒子之一（有 k 种选择，故乘 k），要么单独成一个新的盒子（此时前 n−1 个元素只能占 k−1 个盒子，且新盒子放法唯一，故不乘系数）。因为盒子是无序的，“新建盒子”不会产生额外排列，这是与“第一类斯特林数”或“有序分配”的根本区别。不理解这一点，就无法判断边界和系数的正确性。

困惑二：表格下标与循环范围的错位（off-by-one）。
数学定义中 n、k 从 0 或 1 起步，而 Python 下标从 0 开始，导致三重错位：① 表要开 (n+1)×(k+1) 而不是 n×k；② 循环必须写成 range(1, n+1)，漏掉 +1 会少算一行；③ 内层上界是 min(i, k)，因为 i < k 时值恒为 0，若直接访问 dp[k] 会得到未更新的脏值。此外，k > n 返回 0、S(0,0)=1 这两个边界一旦缺失，整个表会全零或整体偏移。

困惑三：滚动数组为什么要逆序更新？
这是最隐蔽的坑。状态转移需要“上一行”的 dp[j] 和 dp[j-1]。如果正序遍历，dp[j-1] 会被先更新成本行的值，导致 dp[j] 用错数据，结果系统性偏大。初学者通常能写出二维版本，但一做空间优化就出错，因为他们只记住了“能省空间”，没记住“省空间的前提是依赖方向”。

我会怎么讲

针对困惑一：不讲公式，先动手。给 3 个学生分 2 组，让学生枚举所有分法（共 3 种），再追问：“加入第 4 个人时，原来的每种分法能长出几种新分法？”让学生在纸上画出“接进旧盒 / 自立新盒”两棵树，自己数出系数 2 和 1，最后再把树翻译成 k·S(n-1,k) + S(n-1,k-1)。先有组合图像，再有代数式。
针对困惑二：教一个硬规矩——“数学下标几，数组下标就几，宁可多开一格”。强制要求先把边界行手写出来（S(0,0)=1；S(n,0)=0；S(n,n)=1），再写循环，最后用 S(4,2)=7、S(5,3)=25 两个手算可验的小数据做回归测试。同时强调：凡是 k>n 的路径必须第一时间返回 0，作为防御性编程的第一道闸门。
针对困惑三：在黑板上画一张 5×5 的表，用两种颜色标出计算 S(i,j) 时真正需要的两个格子（正上方和左上方），然后问：“如果从左往右填，左上方那个格子还是原来的颜色吗？”让学生亲眼看到它被覆盖。结论落在一条可迁移的口诀上：一维优化时，谁依赖左边的旧值，谁就倒着走。（背包问题同理。）

最常见的错误与规避方法
错误   后果   规避
忘记 S(0,0)=1，表全初始化为 0   整张表全 0   把 S[0][0]=1 写在建表语句下一行，形成肌肉记忆

循环写成 range(1, n)   少算一行，结果偏小   统一约定：循环上界 = 数学上界 + 1

不处理 k > n / k == 0   返回错误值或越界   函数开头做守卫（guard clause）

一维数组正序更新   结果系统性偏大且难以察觉   倒序；或用两个数组 pre/cur 显式区分，牺牲一点空间换正确性

递归不加记忆化   n≈30 就卡死   要么迭代，要么 @lru_cache

混淆“盒子有序/无序”   把答案算成 k!·S(n,k)   明确题目是否区分盒子；若要区分，最后乘 k!

大 n 不取模   Python 虽不溢出但极慢、输出巨大   工程场景在每步 + 和 * 后取模

自检三件套（写完必跑）：① S(n,n)=1；② S(n,2)=2^(n-1)-1；③ Σ_k S(n,k) = 贝尔数（如 n=5 时为 52）。三条都过，基本可确认无误。

"""
【算法思想概览】
第二类斯特林数 S(n, k)：把 n 个「互不相同」的球，放进 k 个「完全相同」的盒子，
要求每个盒子非空，共有多少种放法？（盒子无序 ⇒ 不能简单用 k^n 去重）

核心思路：盯住最后一个球（第 n 个球），它只有两种去向 ——
  A) 挤进已有的某个盒子里：前 n-1 个球已占满 k 个盒子（S(n-1,k) 种），
     第 n 个球有 k 个盒子可选 ⇒ 贡献 k * S(n-1, k)
  B) 自己单独住一个新盒子：前 n-1 个球只能占 k-1 个盒子 ⇒ 贡献 S(n-1, k-1)
两者相加即得递推式：S(n,k) = k*S(n-1,k) + S(n-1,k-1)

实现方式：自底向上的动态规划。从 S(0,0)=1 出发，逐行把三角表填到第 n 行。
边界：S(0,0)=1；n>0 时 S(n,0)=0；k>n 时 S(n,k)=0；S(n,n)=1（由递推自然得出）。
"""

def stirling2_teaching(n: int, k: int) -> int:
    # ---------- 0. 参数合法性守卫：数学上不可能的情况直接返回 0 ----------
    if n < 0 or k < 0:          # 负数无定义
        return 0
    if k > n:                   # 盒子比球多，必有空盒 ⇒ 0 种
        return 0
    if k == 0:                  # 没有盒子：只有「也没有球」时算 1 种（空划分）
        return 1 if n == 0 else 0

    # ---------- 1. 建表：开 (n+1) x (k+1)，让数组下标 = 数学下标 ----------
    # ⚠️ 注意：必须多开一行一列！数学上要访问 S[n][k]，若开 n x k 会越界
    S = [[0] * (k + 1) for _ in range(n + 1)]

    # ---------- 2. 设定唯一种子：S(0,0) = 1 ----------
    # ⚠️ 注意：这是整张表的「唯一起点」。若漏掉这一行，后面全部是 0+0=0
    S[0][0] = 1

    # ---------- 3. 逐行填表：i = 当前球的个数（从 1 到 n）----------
    for i in range(1, n + 1):
        # j = 当前盒子的个数。上界取 min(i, k)：
        # 盒子数不可能超过球数，超过的部分恒为 0，不必计算
        for j in range(1, min(i, k) + 1):
            # ---------- 4. 核心递推：两种去向相加 ----------
            # j * S[i-1][j]   ：第 i 个球加入已有的 j 个盒子之一（j 种选择）
            # S[i-1][j-1]     ：第 i 个球独占一个新盒子，其余 i-1 个球占 j-1 盒
            # ⚠️ 注意：这里用的是「上一行」i-1 的值，所以外层 i 必须从小到大走
            S[i][j] = j * S[i - 1][j] + S[i - 1][j - 1]

    # ---------- 5. 答案就在表的右下角 ----------
    return S[n][k]
