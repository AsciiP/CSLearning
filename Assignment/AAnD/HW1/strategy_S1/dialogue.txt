【我的提问】

请用 Python 实现第二类斯特林数 S(n, k)。递推关系为：S(n,n)=1，S(n,1)=1，
S(n,k)=k×S(n-1,k)+S(n-1,k-1)。
你的回答中，除了代码本身之外，不得包含任何解释、推理或说明文字。代码内部也不得
包含任何注释（即不得出现  //  或  #  等注释符号）。只返回完整的代码。

============================================================
【AI 的完整回答】

def stirling(n, k):
    if n == k or k == 1:
        return 1
    return k * stirling(n - 1, k) + stirling(n - 1, k - 1)
