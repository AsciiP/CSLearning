递推关系的数学含义

第二类斯特林数 S(n, k) 表示将 n 个有区别的元素划分成 k 个非空且无区别的集合（也叫"块"或"子集"）的方案数。

递推关系 S(n, k) = k × S(n-1, k) + S(n-1, k-1) 的含义是：考虑第 n 个元素，它有两种去向：
加入已有的某个块：前 n-1 个元素已经划分成了 k 个块，第 n 个元素可以加入其中任意一个块，有 k 种选择，所以贡献为 k × S(n-1, k)。
单独成为一个新块：前 n-1 个元素划分成了 k-1 个块，第 n 个元素自己单独成一个块，贡献为 S(n-1, k-1)。

两者相加即为总方案数。

基准情形

基准情形有两个：
S(n, n) = 1：将 n 个元素划分成 n 个非空块，每个元素必须单独成一块，只有一种方案。
S(n, 1) = 1：将 n 个元素划分成 1 个块，所有元素必须在同一个块里，只有一种方案。

这两个是基准，因为它们是递归的"终点"——当 k 等于 n 或 k 等于 1 时，答案可以直接确定，无需继续递归。

递归情形的逻辑

递归情形 S(n, k) = k × S(n-1, k) + S(n-1, k-1) 中，n 每次减 1，而 k 要么保持不变、要么减 1。因此 n 会不断减小，最终必然会达到以下两种情况之一：
n 减小到等于 k（此时触发 S(n, n) = 1）
k 减小到 1（此时触发 S(n, 1) = 1）

所以递归一定会终止。

边界情况 n=0 或 k=0

S(0, 0) = 1：将 0 个元素划分成 0 个块，这是一种"空划分"，约定为 1 种方案（组合数学中的惯例）。
S(n, 0) = 0（n > 0）：将正数个元素划分成 0 个块，不可能，返回 0。
S(0, k) = 0（k > 0）：将 0 个元素划分成正数个非空块，不可能，返回 0。

完整代码

def stirling_second(n: int, k: int) -> int:
    """
    计算第二类斯特林数 S(n, k)
    表示将 n 个有区别的元素划分成 k 个非空无区别集合的方案数
    """
    # 边界情况
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0

    # 基准情形
    if n == k:
        return 1
    if k == 1:
        return 1

    # 递归情形
    return k * stirling_second(n - 1, k) + stirling_second(n - 1, k - 1)

记忆化版本（避免重复计算，效率更高）
from functools import lru_cache

@lru_cache(maxsize=None)
def stirling_second_memo(n: int, k: int) -> int:
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0
    if n == k:
        return 1
    if k == 1:
        return 1
    return k * stirling_second_memo(n - 1, k) + stirling_second_memo(n - 1, k - 1)

动态规划版本（适合大规模计算）
def stirling_second_dp(n: int, k: int) -> int:
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0
    if k > n:
        return 0

    # 创建二维表
    dp = [[0] * (k + 1) for _ in range(n + 1)]
    dp[0][0] = 1

    for i in range(1, n + 1):
        for j in range(1, min(i, k) + 1):
            if j == 1 or i == j:
                dp[i][j] = 1
            else:
                dp[i][j] = j * dp[i - 1][j] + dp[i - 1][j - 1]

    return dp[n][k]
